01. COMO USAR NO VS CODE
  1. Extraia este ZIP para uma pasta no seu computador.
  2. Abra a pasta no VS Code.
  3. Abra index.html com a extensão Live Server.
  4. Não precisa de npm, Next.js ou React.

02. COMO ENVIAR AO GITHUB
  1. Entre no repositório do Almanaque, em Add file > Upload files.
  2. Selecione TODOS os arquivos deste ZIP e envie juntos.
  3. Todos estão na raiz, SEM SUBPASTAS.
  4. No Vercel, configure como projeto estático (sem build/npm).

06. CONFIGURAR O PAINEL ADMINISTRATIVO
  1. No painel Supabase, acesse Authentication > Users.
  2. Crie/convide a conta de login da responsável pelo site.
  3. Copie o UUID (ID do usuário) criado no Supabase Auth.
  4. No SQL Editor, execute este comando, SUBSTITUINDO pelo UUID real:

     insert into public.admin_users (user_id)
     values ('COLE_AQUI_O_UUID_REAL')
     on conflict (user_id) do nothing;

  5. Acesse admin.html e entre com e-mail e senha.
  6. Na aba Produtos, use 'Arquivos privados dos produtos'.
  7. Escolha cada produto e seu PDF correspondente no ZIP privado.
  8. Clique em 'Enviar PDF com proteção' para guardá-lo no bucket privado.
  9. O administrador poderá conferir o download privado do arquivo.

  IMPORTANTE: O painel não cadastra usuários públicos por segurança.
  A tabela admin_users está vazia até a conta responsável ser autorizada.

  - Backend seguro (Supabase Edge Function ou Vercel Functions) para gerar checkout.
  - Webhook para confirmar pagamento APROVADO no Mercado Pago.
  - Validar valor/id do produto no servidor, não confiar em valor do navegador.
  - Entregar acesso temporário ao PDF no bucket privado após aprovação.
  - Testar pagamento aprovado, recusado, cancelado, reembolso e reenvio de acesso.
  - Criar política de atendimento de reembolso com canal de contato verificável.
  - Somente após tudo isso, marcar os produtos ativos no painel e definir
    CHECKOUT_ENDPOINT em config.js.

  NUNCA coloque tokens do Mercado Pago nem chave SERVICE_ROLE no config.js!
  NÃO crie um link público permanente para PDFs completos.

    não é emoji nem um simples efeito typewriter.
  - Os movimentos respeitam a preferência de movimento reduzido do navegador.
  - Capa do livro com profundidade 3D discreta, amostra clicável,
    entradas suaves de seções e microinterações em botões e cards.
  - O primeiro pensamento continua grátis, sem cadastro, antes da oferta.
  - Não há rostos artificiais, avaliações fabricadas nem notas inventadas.
  - Referências de teste: a página foi validada em telas de 320, 390, 820
